## The line

> I've been at 1% for an hour. I wasn't dying — I was waiting to see if you'd put me down and go outside. You didn't. Goodbye.

124 characters, one line, plain text.

## Why this line

The phone was never dying at all. It sat at 1% for an hour on purpose,
running a test on its owner: would they finally put the phone down and go
outside? They didn't — so the phone gives up on them and leaves first.
The joke is a fake-out (dying complaint turns into the phone quitting on
the owner), with the sharp two-word verdict — "You didn't." — as the final
beat. It deliberately avoids the genre's stock moves the judge names in
the bounty brief: no will reading, no goodbye to the charger, no pun on
1 percent.

## How it works

`main.ts` holds the line as a single constant, validates it against the
bounty gate (1–199 characters, one line, valid UTF-8, no control
characters), and writes it to `/output/entry.txt` with no trailing
newline, so the file is exactly the line the judge reads.
